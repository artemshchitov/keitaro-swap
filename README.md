# keitaro-swap

Замена лендингов и офферов в кампаниях Keitaro (поиск по названию, отбор кампаний по вхождению ID кабинета в нейминг).

- `keitaro_swap_bookmarklet.txt` — букмарклет: содержимое файла целиком вставить в URL закладки браузера, кликать на открытой вкладке админки КТ.
- `keitaro_swap_bookmarklet.js` — читаемый исходник букмарклета.
- `keitaro_swap.py` — то же консольно (python 3, без зависимостей; ключ через env `KEITARO_URL` / `KEITARO_API_KEY`).

Замена идёт в потоках со схемой `landings` через `PUT /admin_api/v1/streams/{id}`, доли поровну. Перед записью показывается план БЫЛО → СТАНЕТ.
